# ArtFlow Manager

**Массовая обработка папок и файлов по списку артикулов.**

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)]()

## О программе

Настольное приложение для Windows, помогает навести порядок в больших коллекциях файлов, названных по артикулам. Умеет:

- сканировать папки по маскам (`*_01`, `*_pr`, `*.psd`);
- сравнивать шаблоны («есть один, нет второго»);
- фильтровать по списку артикулов (`txt / csv / xlsx / docx`);
- массово переименовывать, копировать, перемещать, удалять в Корзину;
- работать с папками и файлами внутри — отдельно или вместе;
- откатывать последнюю операцию.

## Установка

Требуется **Python 3.8+**.

```bash
pip install send2trash openpyxl python-docx
python ArtFlow_Manager.py
```

## Использование

1. Выберите корневую папку.
2. Настройте скан: маска, расширения, список артикулов.
3. Нажмите **Сканировать**.
4. Отметьте нужные папки в таблице.
5. Настройте действие редактора и нажмите **Применить**.
6. При необходимости — **Отменить последнюю операцию**.

Полная инструкция — в программе, кнопка **📖 Справка**.

## Зависимости

| Библиотека | Назначение |
|---|---|
| send2trash | Удаление в Корзину Windows |
| openpyxl | Чтение `.xlsx` |
| python-docx | Чтение `.docx` |

Все зависимости опциональны — без них часть функций отключается.
